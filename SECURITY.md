# Безопасность

Нашли уязвимость? Пожалуйста, не публикуйте её в открытом issue.

- Сообщите владельцу форка через [форму закрытого отчёта GitHub](https://github.com/GolubiatnikovRoman/3x-ui-kit-custom/security/advisories/new), если она доступна в репозитории.
- Опишите, где проблема (файл и строки), как её воспроизвести и чем она грозит.

## Что проект делает для безопасности

- Установщик 3X-UI закреплён по версии **и** по SHA256: если файл на GitHub изменится,
  скрипт его не запустит.
- Установщик CUSTOM берёт `kit.sh` и `kit-sub.py` из локального checkout закреплённого коммита.
- Обновления KIT отключены до первого подписанного релиза CUSTOM. Для их включения
  потребуется открытый ключ форка. Проверка обновления сверяет подпись `SHA256SUMS`,
  версию в манифесте и SHA256 каждого загруженного файла.
- Резервная копия `kit backup` доступна только root (права 600).
- Подписка `kit-sub` работает без прав root: systemd `DynamicUser` и `LoadCredential`.
- Все данные, которые попадают в файлы настроек, проверяются и экранируются.
- Генераторы конфигов для роутеров работают только в браузере и никуда не отправляют ваши ссылки.

## Ограничения

Скрипт ставит стороннее ПО: панель 3X-UI, ядро Xray, Hysteria, nginx. Мы закрепляем их версии,
но не проверяем их исходный код целиком. Сгенерированный конфиг Mihomo скачивает списки
сайтов (rule-set) и веб-панель zashboard (закреплённой версии) из их проектов на GitHub.
